
# AI-Based Fake Job and Internship Scam Detector

## Project Overview
FakeJobDetector is a web-based application that helps students identify potentially fake job offers and internship scams. Users can enter a job description and receive an AI-based prediction, risk assessment, warning signs, and safety suggestions.

## Features
- AI-based job offer classification
- Fake and genuine prediction
- High, Medium, and Low risk assessment
- Detection of suspicious warning phrases
- Chatbot for job scam awareness
- MongoDB Atlas database to store scan history
- Online website deployment using Render

## Technologies Used
- Python
- Flask
- Scikit-learn
- Pandas
- HTML and CSS
- MongoDB Atlas
- GitHub
- Render

## How It Works
1. The user enters a job description.
2. The AI model predicts whether the offer is Fake or Genuine.
3. The application displays a risk level and warning signs.
4. The scan result is saved in MongoDB Atlas when the database connection is available.
5. Users can ask job-safety questions through the chatbot.

## Live Website
https://fakejobdetector-m6su.onrender.com/

## Important Note
This application provides an initial screening only. Its predictions may be incorrect. Always verify job offers through official company websites and never pay unexpected recruitment fees.

## Project Purpose
The purpose of this project is to help students become more aware of fake job offers and internship scams.
